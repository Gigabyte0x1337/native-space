# Finite Boolean Logic Kernel

## Scope

This document proves the paper semantics of the finite propositional checker.
It is not a proof of the Rust implementation and does not extend these results
to native-state equality, quantifiers, induction, or analytic propositions.

### D-BLOGIC-1 -- formulas and valuations [Definition]

A formula is generated by Boolean constants, declared variables, and the
functions NOT, AND, OR, XOR, IMPLIES, and IFF with their standard truth
functions. A valuation maps every declared variable to exactly one Boolean
value. Evaluation is the structural recursion induced by those truth functions.

### D-BLOGIC-2 -- tautology certificate [Definition]

For an ordered variable tuple $(v_1,\ldots,v_n)$, a truth-table certificate
is valid when the formula evaluates to true for every one of the $2^n$
valuations in lexicographic false-before-true order, and all serialized metadata
equals the metadata reconstructed from the formula.

### T-BLOGIC-SOUND-1 -- accepted formulas are tautologies [Proved]

**Claim.** Every formula accepted by the truth-table compiler is true under
every valuation of its declared variables.

**Proof.** The compiler enumerates the Cartesian product
$\{\mathsf{false},\mathsf{true}\}^n$. This set is exactly the set of all
valuations of the $n$ ordered variables. Acceptance occurs only if structural
evaluation returns true for every member. Therefore the formula is true under
every valuation, which is the definition of a tautology. $\square$

### T-BLOGIC-COMPLETE-1 -- every supported tautology is accepted [Proved]

**Claim.** Every well-formed supported formula that is a tautology and has at
most the implementation limit of variables is accepted.

**Proof.** By definition a tautology is true under every valuation. The
enumeration covers every valuation exactly once, so no counterexample is found
and the compiler emits its certificate. The variable limit is an explicit
backend bound, not a logical restriction on propositional tautologies.
$\square$

### T-BLOGIC-COUNTER-1 -- rejection supplies a real counterexample [Proved]

**Claim.** When the compiler rejects a well-formed formula as non-tautological,
the reported assignment makes the formula false.

**Proof.** Rejection occurs at the first enumerated valuation whose structural
evaluation is false. The reported assignment is that exact valuation.
$\square$

### T-BLOGIC-VERIFY-1 -- accepted certificates reconstruct [Proved]

**Claim.** A certificate accepted by the verifier contains a supported
tautology and exact reconstructed metadata.

**Proof.** The verifier checks the closed envelope, reconstructs and validates
the formula, reruns the complete truth-table decision, regenerates the
certificate, and requires structural equality with the supplied artifact.
Hence acceptance implies both T-BLOGIC-SOUND-1 and exact metadata agreement.
$\square$

## Boundary

These results prove only finite propositional validity. In particular, a
Boolean formula cannot prove a convergence, zeta-zero, or RH statement unless
those mathematical predicates first receive independently proved semantics.
