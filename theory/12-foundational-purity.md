# Foundational Purity Program

No nonempty mathematical system is proved from literally nothing. Native Space
therefore uses this falsifiable definition:

> A layer is **foundationally native** when every object and theorem in that
> layer is derived from the declared kernel A-IND-1 using explicit definitions,
> and no classical camera or unexpanded analytic axiom is a proof premise.

Classical cameras may remain as verification outputs. They do not make a layer
impure unless a native theorem depends on them.

### A-IND-1 -- minimal trusted inductive kernel [Axiom]

The kernel provides only:

- finite inductive data generated by constructors;
- decidable constructor equality;
- definition by primitive recursion; and
- structural induction and ordinary equality substitution.

It contains no real or complex numbers, primes, limits, logarithms, zeta,
geometry, or Native Space operation as a primitive. This is the irreducible
metatheoretic trust boundary chosen by the project; it is not labeled a theorem
proved by Native Space.

## Constructed exact arithmetic

### D-PNAT-1 -- constructed naturals [Definition]

Construct $\mathbb{N}_P$ from `zero` and `successor`. Define ADD and MULTIPLY
by primitive recursion. Define order by
$a\leq b$ when $a\boxplus c=b$ for some constructed natural $c$.

### D-PINT-1 -- constructed integers [Definition]

Use canonical sign-and-magnitude values: zero, positive successor magnitude,
or negative successor magnitude. Integer ADD and MULTIPLY are finite case
definitions over natural magnitude operations.

### D-PRAT-1 -- constructed rationals [Definition]

A nonzero rational is a canonical pair $(z,d)$, where $z$ is a constructed
integer, $d$ a positive constructed natural, and numerator and denominator
are reduced by the constructed Euclidean gcd with positive denominator. Zero
has the unique form $(0,1)$.

T-QARITH-1 in `../proofs/20-foundational-purity.md` proves that these canonical
values form an ordered field $\mathbb{Q}_P$ relative only to A-IND-1.

## Exact rational Native Space

### D-QOS-1 -- pure exact oriented scalar [Definition]

Define

$$
\mathbb{O}_P:=\mathbb{Q}_P\times\mathbb{Q}_P
$$

with the existing native ADD and MULTIPLY formulas, quarter orientation, zero,
one, conjugation, squared size, and nonzero inverse.

### D-QIDX-1 -- pure finite index [Definition]

An index is a finite canonical sequence of pairs
$(k,d)$ with positive constructed natural direction and depth, sorted by
direction. Index composition merges equal directions by constructed natural
ADD.

### D-QNS-1 -- pure finite native state [Definition]

A state is a finite canonical sequence of distinct D-QIDX-1 locations with
nonzero D-QOS-1 coefficients. Native ADD merges matching locations;
MULTIPLY performs finite convolution; ORIENT acts coefficientwise; INDEX adds
one selected constructed depth.

T-QOS-1 and T-QCORE-1 prove that this exact carrier satisfies the four-operation
core laws relative only to A-IND-1. It is the mathematical target implemented
by the exact-rational interpreter and VM.

## Construction order

1. exact constructed naturals, integers, rationals, indices, and finite states;
2. Cauchy real completion and complete oriented scalars;
3. native limits, series, derivatives, exponential flow, and logarithm;
4. operations-first continuation of the zeta coordinate;
5. zeta-specific zero-fiber theorem;
6. only then, if the final implication closes, K-RH-1 may become proved.

Self-representation does not shorten this dependency order: encoding a rule as
a native object does not prove the rule sound. Each construction must still
carry its invariant and proof.
